# Audit sistem dan hardening regresi M3C Learning Line

Tanggal audit: 8 Oktober 2026. Acuan UI-4 terbaru yang diintegrasikan: `origin/main` **943dec6bb976e1ae79c9711bde8819afcedd2fb3** (line 3D realistis, landing). Sesi awal gagal membuat `app/cameras` karena `Permission denied`; sesi pemulihan berhasil melakukan rebase normal setelah perubahan BE/dokumen disimpan sebagai commit lokal. Cadangan terverifikasi ada di `../M3C-Pilot-Data/M3C-Audit-Backup-2026-10-08.zip` (SHA-256 `074B397F0815A80123E60C8907FF216808F864084FF72DA74BF036A99AA99D3D`). Semua validasi domain menggunakan MemoryStore dengan `DATABASE_URL` kosong; database produksi tidak diakses.

## Ringkasan eksekutif

Alur inti MemoryStore dan kontrak BE setelah perbaikan lolos 108 test pada 22 file, lint, typecheck, `npm ci`, build, seed deterministik, dan smoke BE-4 di checkout UI-4 yang sudah terintegrasi. Build lulus dengan satu warning fallback font `Big Shoulders`. HTTP SSR lokal sebelumnya mengembalikan 200 untuk landing, Station st-04/st-06, Shift Board, Cameras, Kaizen, Knowledge, Metrics, Simulator. Uji browser interaktif penuh dan Postgres terisolasi **belum terverifikasi**, sehingga sistem belum dapat dinyatakan bebas defect. Tiga isu screenshot harus dibedakan: tombol operator yang disabled adalah aturan benar; st-04 tanpa open alert adalah seed benar; st-06 offline tanpa defect alert adalah pemisahan fakta benar tetapi UI menyembunyikan health saat navigasi.

Inventaris: **5 bug BE diperbaiki** (2 P1, 3 P2), **3 bug UI P1**, **7 issue UI P2**, **1 issue copy UI P3**, **2 risiko/deployment P1**, **2 blocker validasi P2 yang kini terselesaikan**, serta **3 perilaku domain yang diharapkan** yang tidak dihitung sebagai bug. Temuan UI dikumpulkan sekali di [handoff terpadu](UI_HANDOFF_2026-10-08.md). Angka ini adalah klasifikasi temuan yang dibuktikan oleh code/SSR/test; browser dapat menambah temuan.

## Audit state machine dan konsistensi lintas layar

| Transisi | Prasyarat/otoritas/hasil | Bukti dan sisa risiko |
|---|---|---|
| Kamera → open alert | Simulator true defect mencipta alert st-04; kamera offline st-06 hanya gap. | `getCameraView`, `getStationView`, flow test. Tidak ada defect palsu. |
| Open → confirm/reject | Operator saja; confirm menjadi pending TL/yellow andon; reject perlu reason dan masuk review. | Action dan test role/duplikat. Confirmed tidak disembunyikan budget false alarm. |
| Rejected → verified review | TL memverifikasi kumpulan rejection operator; baru eligible model update. | BE-02 fix/test. Model review terpisah dari containment. |
| Confirmed → shift decision | TL + note; stop/contain/continue persisten; tidak ada auto stop. | SSR operator/TL, action flow, concurrent click test. Multi-tab browser belum teruji. |
| Stop → restart | Hanya TL + repair note; counter produksi ditolak saat stopped. | Flow test. Progress visual per takt memerlukan UI-10. |
| Repeat ketiga → Kaizen | Kunci atomik MemoryStore; `injectRepeat3` fixture sintetis membuat tepat satu ticket dengan 3 alert cocok. | Empat concurrent injection pada flow test. Postgres isolation belum diuji. |
| A3 → senior validation → knowledge | Engineer mengisi root cause/countermeasure, bukan AI; senior return/revise/validate; hanya validated citation. | BE-01/05 fixes, test workflow assistant cited/no-card. UI revisi belum tersambung. |
| Reset/reload/cross-page | Seed hash `affa75a6…`, 8 kamera, 9 event, line running; action revalidates pages. | Smoke + SSR. Browser polling/reload/multi-tab NOT_VERIFIED. |

Konsistensi identitas `stationId`, `alertId`, `bodyId`, defect, criticality, event time, keputusan, line, ticket, card berasal dari snapshot/view BE yang sama. Station no-alert sesudah keputusan harus menampilkan history, bukan memberi kesan tidak pernah ada alert. `getOverviewView/getTrailView` hanya membangun langkah dari entity nyata. Tidak ada MES yang melacak lokasi body saat ini; `flaggedBody.currentLocationStationId=null` sengaja. KPI `getMetricsView/getPilotView` simulasi, baseline casebook, dan target terpisah provenance. `getSimulatorView` fingerprint/reset deterministik.

## Media, pilot, dan integritas sumber

Manifest pilot lokal diperiksa tanpa memindah raw data ke repo: delapan SVG generated mempunyai hash SHA-256 cocok; delapan referensi terkurasi ada, tujuh mapping kanonis dan satu external-only. Mapping yang disetujui `good→NORMAL`, `gap→BEAD_BREAK`, `overlap→BEAD_EXCESS` hanya visual. Kelas eksternal lain tidak dipaksa menjadi `BEAD_OFFSET`. MP4/poster di `public/cams` ada; media publik diberi sumber referensi dalam metadata, bukan CCTV TMMIN atau input KPI. Kamera offline/gap tidak punya frame rekaman baru. Time model memakai reference seed 2027 yang deterministik, berbeda dari tanggal nyata 2026; `CameraView.asOf` membantu label waktu simulasi. Footer wajib tetap "Concept prototype · simulated data · not connected to TMMIN systems".

## Risiko tersisa dan keputusan integrasi

UI-01/02/03 adalah blocker pengalaman Station/kamera dan integritas representasi media. UI harus mengimplementasikan satu paket handoff lalu menjalankan acceptance browser pada desktop/tablet/HP. Shared Postgres state dan persona cookie perlu keputusan produk sebelum demo publik multi-pengunjung; jangan menyebutnya autentikasi produksi. Warning fallback font dan advisory tool pengembangan tetap tercatat. Postgres isolated memerlukan test DB aman. Salinan audit sementara dan cache npm tetap untracked, tidak dimasukkan ke Git. Audit ini tidak menjanjikan tidak ada defect lain.
